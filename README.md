# kr-geo — 한국어 고객 질문부터 시작하는 AEO/GEO 스킬

VibeRick이 만든 한국어 웹사이트 콘텐츠 점검·개선 지침입니다. 고객이 묻는 질문, 실제 서비스 정보, 페이지 근거를 연결합니다. Google과 네이버의 기준을 구분하고 사이트 준비 상태와 실제 AI 언급·추천·인용을 따로 기록합니다.

## 무엇을 하나요?

- 한국어 고객 질문에 현재 페이지가 답하는지 확인하고, 기존 페이지 보완과 새 글 작성을 구분합니다.
- 실제 사업 정보와 경험으로 콘텐츠를 개선합니다. 없는 가격·후기·성과를 만들지 않습니다.
- 저장한 HTML에서 제목·설명·헤딩·canonical·robots meta·JSON-LD 문법을 확인합니다.
- AI 답변을 비교할 때 질문·서비스·날짜·언어·조건과 실제 인용 URL을 기록하도록 안내합니다.

검색 순위나 AI 추천을 보장하지 않습니다. 네이버 블로그·플레이스 전체 운영 도구가 아니며, Search Console 인증이나 다중 엔진 API 수집을 자동 수행하는 프로그램도 아닙니다. 브라우저·검색·코드 수정 능력은 사용하는 에이전트 환경에 따릅니다.

## Claude Code에 설치

프로젝트 폴더에서 실행합니다. 같은 폴더가 이미 있으면 덮어쓰지 말고 기존 내용을 먼저 확인하세요.

```sh
mkdir -p .claude/skills
git clone https://github.com/VibeRick/kr-geo.git .claude/skills/kr-geo
```

새 Claude 세션에서 사용하세요:

```text
kr-geo로 내 홈페이지를 보고 고객 질문과 부족한 답변을 찾아줘.
```

Codex 등 Agent Skills를 읽는 환경에서는 프로젝트 `.agents/skills/kr-geo`에 같은 저장소를 복제할 수 있습니다. 현재 에이전트의 스킬 목록에서 인식 여부를 확인하세요.

## 짧은 사용 예

```text
내 홈페이지를 보고 어떤 고객이 무슨 질문으로 찾아올지 정리해줘.
한국어 표현과 네이버 맥락도 고려해줘.
```

```text
이 질문에 답하도록 기존 페이지를 보완해줘. 실제 경험과 확인된 사실만 써줘.
```

```text
이 AI 답변들에서 우리 브랜드 언급과 실제 출처 링크를 구분해줘.
```

## 선택: 오프라인 HTML 점검

Python 3.10+ 표준 라이브러리만 사용합니다. 별도 패키지·네트워크·API 키는 필요하지 않습니다.

```sh
python3 scripts/inspect_html.py saved-page.html --url https://example.com
```

결과의 `ai_visibility`는 항상 `null`입니다. 이 스크립트는 저장된 HTML만 읽으며 실제 검색엔진 접근·색인·콘텐츠의 사실성·AI 인용률을 측정하지 않습니다. 검색 상태는 공식 도구와 실제 관측으로 별도 확인합니다.

## 출처와 공개 범위

VibeRick Web Craft Kit의 자체 kr-geo 지침과 오프라인 검사기를 독립 배포한 0.1.0입니다. 고객 자료·계정·실측 보고서·녹화본은 포함하지 않습니다. 외부 스킬 코드를 묶지 않았습니다. 공식 문서 링크는 SKILL.md에 있으며 변경 가능한 정책은 작업 시 다시 확인하도록 되어 있습니다.

## 검증 범위

스킬 형식 검사, 합성 한국어 HTML의 메타데이터 추출, 잘못된 JSON-LD 및 복수 canonical 탐지를 확인했습니다. 실제 모델의 행동·검색 성과를 검증했다는 뜻은 아닙니다.
